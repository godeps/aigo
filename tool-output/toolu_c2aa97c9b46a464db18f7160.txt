     1	调用DoMetaQuery接口查询满足指定条件的文件（Object），并按照指定字段和排序方式列出文件信息。您也可以通过Query的嵌套使用实现复杂查询，以及通过聚合操作实现对不同字段的值进行统计和分析。
     2	
     3	## 注意事项
     4	
     5	要查询满足指定条件的文件，您必须有`oss:DoMetaQuery`权限。具体操作，请参见[为RAM用户授予自定义的权限策略](https://help.aliyun.com/zh/oss/common-examples-of-ram-policies#section-ucu-jv0-zip)。
     6	
     7	## 请求语法
     8	
     9	### **标量检索**
    10	
    11	```
    12	POST /?metaQuery&comp=query&mode=basic HTTP/1.1
    13	Host: BucketName.oss-cn-hangzhou.aliyuncs.com
    14	Date: GMT Date
    15	Authorization: SignatureValue 
    16	<?xml version="1.0" encoding="UTF-8"?>
    17	<MetaQuery>
    18	  <NextToken></NextToken>
    19	  <MaxResults>5</MaxResults>
    20	  <Query>{"Field": "Size","Value": "1048576","Operation": "gt"}</Query>
    21	  <Sort>Size</Sort>
    22	  <Order>asc</Order>
    23	  <Aggregations>
    24	    <Aggregation>
    25	      <Field>Size</Field>
    26	      <Operation>sum</Operation>
    27	    </Aggregation>
    28	    <Aggregation>
    29	      <Field>Size</Field>
    30	      <Operation>max</Operation>
    31	    </Aggregation>
    32	  </Aggregations>
    33	</MetaQuery>
    34	```
    35	
    36	### **向量检索**
    37	
    38	```
    39	POST /?metaQuery&comp=query&mode=semantic HTTP/1.1
    40	Host: BucketName.oss-cn-hangzhou.aliyuncs.com
    41	Date: GMT Date
    42	Authorization: SignatureValue 
    43	<?xml version="1.0" encoding="UTF-8"?>
    44	<MetaQuery>
    45	  <MaxResults>99</MaxResults>
    46	  <Query>俯瞰白雪覆盖的森林</Query>
    47	  <MediaTypes>
    48	    <MediaType>image</MediaType>
    49	  </MediaTypes>  
    50	  <SimpleQuery>{"Operation":"gt", "Field": "Size", "Value": "30"}</SimpleQuery>
    51	</MetaQuery>
    52	```

   561	## Query示例
   562	
   563	Query支持嵌套使用，您可以通过Query的嵌套构建复杂的查询条件，精确查询到所需内容。
   564	
   565	-   如果要搜索名称为exampleobject.txt且大小小于1000字节的文件，则Query填写示例如下：
   566	    
   567	    ```
   568	    
   569	    {
   570	      "SubQueries":[
   571	        {
   572	          "Field":"Filename",
   573	          "Value": "exampleobject.txt",
   574	          "Operation":"eq"
   575	        },         
   576	        {
   577	          "Field":"Size",
   578	          "Value":"1000",
   579	          "Operation":"lt"
   580	        }
   581	      ],
   582	      "Operation":"and"
   583	    }
   584	                
   585	    ```
   586	    
   587	-   如果要搜索以`exampledir/`为前缀，包含`type=document`或`owner=John`标签且大小大于10 MB的文件，则Query填写示例如下：
   588	    
   589	    ```
   590	    
   591	    {
   592	      "SubQueries": [
   593	        {
   594	          "Field": "Filename",
   595	          "Value": "exampledir/",
   596	          "Operation": "prefix"
   597	        },
   598	        {
   599	          "Field": "Size",
   600	          "Value": "1048576",
   601	          "Operation": "gt"
   602	        },
   603	        {
   604	          "SubQueries": [
   605	            {
   606	              "Field": "OSSTagging.type",
   607	              "Value": "document",
   608	              "Operation": "eq"
   609	            },
   610	            {
   611	              "Field": "OSSTagging.owner",
   612	              "Value": "John",
   613	              "Operation": "eq"
   614	            }
   615	          ],
   616	          "Operation": "or"
   617	        }
   618	      ],
   619	      "Operation": "and"
   620	    }
   621	            
   622	                
   623	    ```
   624	    
   625	
   626	结合以上搜索条件，您还可以通过聚合操作实现不同数据的统计和分析，例如计算符合搜索条件的所有文件的大小总和、数量、平均值或者最值，统计所有符合搜索条件图片的尺寸分布情况。
